# Kronos point-in-time evaluation protocol

This is a frozen, zero-shot feature test for Kronos over July 2024 through June 2026. The [Kronos paper](https://arxiv.org/html/2508.02739#S5) says its pretraining data ends in June 2024, so the evaluation dates follow that stated cutoff. The project has already explored related price rules and universe construction, so this is model-clean by the paper's cutoff but not a pristine project holdout.

The candidate pool comes from Alpaca's active/inactive asset snapshot dated October 4, 2026. For each session, the universe selects the top 25 eligible symbols using only the prior 20 sessions' median dollar volume, with a prior-close floor of $5 and median-dollar-volume floor of $20 million. There are 501 sessions, 12,525 selected ticker-sessions, 68 unique selected symbols, and 25,050 decision inputs. This lagged selector avoids using the decision day's volume, but the current asset snapshot omits some historical delistings and creates survivorship bias.

The morning decision uses the 90 completed 15-minute bars available at 09:45 ET. The afternoon decision uses 90 completed 30-minute bars available at 15:30 ET. Thirty-minute bars are aggregated from the cached 15-minute SIP bars. Kronos-small and its tokenizer remain frozen; inference uses 10 paths and temperature 1.0. The forecast target is the terminal close five subsequent sessions after the decision, with entry at the decision-bar close. This is a feature evaluation, not an order-fill or portfolio backtest.

The interval-specific reports compute cross-sectional rank IC separately by decision cycle. They compare Kronos with 20-day reversal, 12–1 momentum, distance below the 400-session mean, the current-session move, the opening gap, forecast dispersion, and ATR(14). The incremental Kronos diagnostic residualizes the forecast and realized return against reversal, distance below the 400-session mean, current-session return, and opening gap within each cycle. Confidence intervals resample blocks of five consecutive decision cycles, one cycle per session in each interval-specific report. Fixed absolute-value summaries compare SPY-relative forecast errors with a zero-return forecast; no thresholds are fitted.

SPY jobs and forecasts are retained. The report includes raw stock returns and simple SPY-relative returns (beta fixed at one) for market-relative absolute-value analysis. Subtracting one common SPY value from every stock in a decision cycle cannot change cross-sectional rank IC; a diagnostic records the observed difference. This does not make SPY unhelpful: it remains useful for market context, beta-relative thresholds, and later ETF-option research. QQQ or a sector ETF can be added as context in a later protocol.

Adjusted daily bars were backfilled to January 2022 so the 400-session control is fully formed throughout the evaluation window. Ticker-cycles without 400 prior daily sessions or a five-session exit label are counted and excluded. Recent IPOs may therefore have less coverage. Alpaca's `all` adjustment includes split and cash-dividend adjustments ([API definition](https://docs.alpaca.markets/us/reference/stockbarsingle-1)); results are adjusted total-return-like forecasts, not raw spot-price returns. Kronos standardizes each input channel over the 90-bar lookback, so a uniform multiplicative rescaling of a channel cancels from the model input, but these data are still not an as-traded quote series and must not be reused as option prices.

Option returns are outside this run. Evaluating calls or puts requires historical option contracts and quotes, including strike, expiry, bid/ask, and implied volatility; a forecast of the underlying alone cannot establish option profitability. No JEV signal, fine-tuning, position sizing, transaction-cost model, or trade threshold is evaluated here.
