# Kronos point-in-time evaluation protocol

This is a frozen, zero-shot feature test for Kronos over July 2024 through June 2026. The [Kronos paper](https://arxiv.org/html/2508.02739#S5) says its pretraining data ends in June 2024, so the evaluation dates follow that stated cutoff. The project has already explored related price rules and universe construction, so this is model-clean by the paper's cutoff but not a pristine project holdout.

The candidate pool comes from Alpaca's active/inactive asset snapshot dated October 4, 2026. For each session, the universe selects the top 25 eligible symbols using only the prior 20 sessions' median dollar volume, with a prior-close floor of $5 and median-dollar-volume floor of $20 million. There are 501 sessions, 12,525 selected ticker-sessions, 68 unique selected symbols, and 25,050 decision inputs. This lagged selector avoids using the decision day's volume, but the current asset snapshot omits some historical delistings and creates survivorship bias.

The morning decision uses the 90 completed 15-minute bars available at 09:45 ET. The afternoon decision uses 90 completed 30-minute bars available at 15:30 ET. Thirty-minute bars are aggregated from the cached 15-minute SIP bars. The 90-bar warm-up omits the first few sessions: the prepared morning inputs run July 8, 2024–June 30, 2026, and the afternoon inputs run July 11, 2024–June 30, 2026. GME is in the 68-symbol selected universe but appears only on July 1–2, before either prepared interval begins, so it has no forecast rows. Kronos-small and its tokenizer remain frozen; inference uses 10 paths, temperature 1.0, top-p 0.9, and seed 42 reset for each ticker-cycle. The forecast target is the terminal close five subsequent sessions after the decision, with entry at the decision-bar close. This is a feature evaluation, not an order-fill or portfolio backtest.

The interval-specific reports compute cross-sectional rank IC separately by decision cycle. They compare Kronos with 20-day reversal, 12–1 momentum, distance below the 400-session mean, the current-session move, the opening gap, forecast dispersion, and ATR(14). The incremental Kronos diagnostic residualizes the forecast and realized return against reversal, distance below the 400-session mean, current-session return, and opening gap within each cycle. Confidence intervals resample blocks of five consecutive decision cycles, one cycle per session in each interval-specific report. Fixed absolute-value summaries compare SPY-relative forecast errors with a zero-return forecast; no thresholds are fitted.

SPY jobs and forecasts are retained. The report includes raw stock returns and simple SPY-relative returns (beta fixed at one) for market-relative absolute-value analysis. Subtracting one common SPY value from every stock in a decision cycle cannot change cross-sectional rank IC; a diagnostic records the observed difference. This does not make SPY unhelpful: it remains useful for market context, beta-relative thresholds, and later ETF-option research. QQQ or a sector ETF can be added as context in a later protocol.

Adjusted daily bars were backfilled to January 2022 so the 400-session control is fully formed throughout the evaluation window. Ticker-cycles without 400 prior daily sessions or a five-session exit label are counted and excluded. Recent IPOs may therefore have less coverage. Alpaca's `all` adjustment includes split and cash-dividend adjustments ([API definition](https://docs.alpaca.markets/us/reference/stockbarsingle-1)); results are adjusted total-return-like forecasts, not raw spot-price returns. Kronos standardizes each input channel over the 90-bar lookback, so a uniform multiplicative rescaling of a channel cancels from the model input, but these data are still not an as-traded quote series and must not be reused as option prices.

Option returns are outside this run. Evaluating calls or puts requires historical option contracts and quotes, including strike, expiry, bid/ask, and implied volatility; a forecast of the underlying alone cannot establish option profitability. No JEV signal, fine-tuning, position sizing, transaction-cost model, or trade threshold is evaluated here.

The cached inputs were checked against the bar store before inference: all 68 unique selected symbols plus SPY (69 total) are present in both adjusted stores. The manifests identify SIP feed and `all` adjustment for both 1-day and 15-minute bars. Across those symbols, the daily store contains 78,817 rows from January 3, 2022 through October 2, 2026; the 15-minute store contains 2,020,879 rows from July 1, 2024 through October 2, 2026. Prepared inputs contain 12,922 morning jobs across 497 cycles and 12,844 afternoon jobs across 494 cycles; every prepared cycle has 25 stock jobs and exactly one SPY job, and every history has 90 bars. A timestamp audit confirmed histories end before each decision and forecast grids begin at or after it and end on the intended target session. These coverage checks confirm the cached data needed for this experiment, not a complete or survivorship-free market history.

## Results

The complete reports are [09:45 / 15m](kronos-pit-2024-2026-15m-report.md) and [15:30 / 30m](kronos-pit-2024-2026-30m-report.md); the side-by-side chart is [here](kronos-pit-2024-2026-visual.svg). All 12,922 morning and 12,844 afternoon forecasts completed with 10 valid paths each. The evaluator compared 12,094 morning and 12,019 afternoon stock-cycle samples after excluding 331 rows in each interval for insufficient 400-session daily history.

| Metric | 09:45 / 15m | 15:30 / 30m |
|---|---:|---:|
| Cycles / valid stock-cycle samples | 497 / 12,094 | 494 / 12,019 |
| Kronos mean per-cycle rank IC (5-cycle block 95% CI) | +0.001 (−0.034, +0.035) | −0.020 (−0.055, +0.015) |
| Kronos residual rank IC after price controls (95% CI) | −0.004 (−0.035, +0.027) | −0.004 (−0.034, +0.028) |
| SPY-relative MAE: Kronos vs. zero-forecast baseline | 5.434% vs. 4.799% | 5.167% vs. 4.633% |
| Directional accuracy | 50.3% | 49.4% |
| Realized-volatility rank IC: path dispersion vs. ATR(14) | 0.519 vs. 0.703 | 0.544 vs. 0.689 |

Neither decision time shows useful zero-shot directional skill: rank IC is near zero in the morning and negative in the afternoon, both intervals' confidence intervals include zero, and removing simple price controls leaves a residual rank IC of −0.004. The zero-return baseline also has lower absolute SPY-relative forecast error, and directional accuracy is near 50%. ATR(14) ranks realized volatility better than Kronos path dispersion in both intervals. This test gives no evidence to add Kronos to the scoring or risk-sizing pipeline yet; it does not prove that all future intervals or model uses will fail. The 12–1 momentum control has the highest mean rank IC (+0.050 morning, +0.047 afternoon), but both block intervals include zero and this is not an independent replication.

These are two decision-time analyses over the same calendar period and overlapping five-session outcomes, not separate out-of-time holdouts. Subtracting the same SPY return in a cycle changed cross-sectional rank IC by exactly zero; paired SPY forecasts are useful here for absolute market-relative error and later threshold research, not for changing stock ranks.

This experiment does not close M1 or M2. The strict data-quality report remains `FAIL` because `dedupe.jaccard_threshold` and `latency.news_minutes` are unverified (`docs/data-quality-strict.json`). M2 remains incomplete: the JEV memorization probe has not been implemented or run, so there is no measured JEV clean window. This Kronos price-only test does not resolve possible JEV contamination in earlier results.
